# Harley Innovation Hub

The official website for **Harley Innovation Hub**, Lafia's premier technology center, coworking space, and digital skills training provider.

## 🚀 Overview

Harley Innovation Hub is a vibrant ecosystem in Lafia, Nasarawa State, Nigeria, dedicated to fostering innovation, digital literacy, and professional growth. We provide cutting-edge facilities and expert mentorship to help individuals and startups turn their ideas into reality.

## ✨ Features

- **Services**: Software Development, IT Consulting, Digital Marketing, and CCTV Installation.
- **Products**: Innovative digital solutions built by our team.
- **Coworking Space**: A conducive environment with stable power, fast WiFi, and air conditioning.
- **Training**: Specialized programs in Cybersecurity, Data Analysis, Backend & Frontend Development, Product Design, and Data Science.
- **Community**: Networking opportunities with like-minded professionals and industry experts.

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS with Shadcn UI
- **Icons**: Lucide React
- **Animations**: Framer Motion / Tailwind Animate
- **Routing**: React Router DOM

## 📱 Navigation Features

- **Responsive Design**: Optimized for desktop and mobile devices.
- **Mobile Navigation**: Features a streamlined top bar and a convenient bottom navigation bar for an app-like experience.
- **Announcement Banner**: Integrated space for promoting current programs and events.

## 🛠️ Development

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm (comes with Node.js)

### Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Scripts

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the project for production.
- `npm run lint`: Runs ESLint to check for code quality issues.
- `npm run test`: Runs unit tests using Vitest.
